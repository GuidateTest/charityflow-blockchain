1. Summary

SWC-106 = Unprotected selfdestruct. Anyone can destroy the contract and steal all ETH. Severity: High/Critical.

4. Code Fix

Vulnerable: function destroy(address payable _to) external { selfdestruct(_to); }

Fixed: function destroy(address payable _to) external onlyOwner { selfdestruct(_to); }

5. Remediation Checklist

  • Add onlyOwner (or role-based access) to selfdestruct
  • Use multisig for high-value contracts
  • Run Slither/Mythril to detect SWC-106

6. Key Takeaway

Always protect selfdestruct with access control. Real-world example: Parity wallet (~$300M frozen) due to unprotected init + kill.
